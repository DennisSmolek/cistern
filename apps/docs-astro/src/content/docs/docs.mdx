## What is Cistern?

Cistern is a small toolkit for building "galleries in the round" — cistern-shaped exhibition
spaces — with three.js. `@cistern/core` generates profile-revolution `BufferGeometry` with
sectional attributes and a TSL/WebGPU material; `@cistern/camera` extends `camera-controls` with
gallery-aware collision and boundaries; `@cistern/r3f` wraps it all in React Three Fiber
components.
